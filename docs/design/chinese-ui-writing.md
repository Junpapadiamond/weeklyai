# 黑马雷达中文界面规范

## 写给谁

来找 AI 工具、了解新产品的中文用户。先说明产品能做什么，再给亮点、来源和下一步操作。保留「黑马雷达」品牌，以及「黑马」「潜力股」两档分类。

## 页面与用词

| 场景 | 统一用词 | 避免 |
| --- | --- | --- |
| 首页产品列表 | 产品库、近期黑马、往期黑马 | 产品观察、研究档案 |
| 随机浏览 | 随便看看、右滑收藏、左滑跳过 | 挖黑马、连击、惯性右甩 |
| 类别筛选 | 产品分类、智能体、办公效率、可穿戴设备 | 高频方向、Agent、效率 |
| 产品说明 | 产品介绍、产品亮点、最新动态 | 值得研究的原因、记录中的动态 |
| 产品评分 | 黑马指数 | 发现价值评分、实测评分 |
| 日期 | 收录于、最近收录 | 产品发布日期（如果只有收录时间） |
| 操作 | 查看详情、查看演示、生成演示、访问官网 | 了解更多、交互试用、立即体验（指本站演示时） |
| 资讯 | AI 资讯、阅读原文、全部地区 | 博客动态、全球 Hybrid、本土源 |
| 助手 | AI 助手、说说你的需求 | 区域信号、研究假设 |

「黑马指数」衡量发现潜力，不代表实测效果。生成的演示使用示例数据，明确标注为本站制作；访问真实产品使用「访问官网」。生成次数、失败恢复方式要在相关操作旁说清楚。

## 写法

- 用日常句子说明实际用途。例如「将医生与患者的对话整理成病历」，不要写「赋能医疗行业转型」。
- 优先用约定俗成的中文：基础模型、具身智能、数字孪生、种子轮、A 轮融资。保留产品名、公司名以及 AI、API、AR、SaaS 等常用缩写。
- 不用一条句子混写普通英语词组，例如 `wearable AI glasses` 写作「AI 智能眼镜」。
- 产品介绍和亮点避免重复。前者说明用途，后者提供有来源的差异、进展或数字；不从融资额推导质量、可靠性或投资价值。
- 不添加资料中没有的用户数、效果、排名、价格或时效保证。改写时核对币种、单位、日期和产品身份。
- 错误提示说明发生了什么，以及用户可以做什么。不要把服务商密钥、响应解析或内部校验代码直接显示给用户。
- 中英文之间留空格。中文标题不套用全大写英文眉题、过小等宽字体和大字距。
- 导航、页面标题与操作名称保持一致。手机窄屏下优先保留完整的动作名称。

## 这次的布局约定

中文首页优先展示搜索和分类入口，右侧提供「随便看看」「看产品演示」。正文直接进入产品列表；原有暖白、深灰、玫红色板与黑马标识继续使用。公司图标沿用 SmartLogo，不替换成字母占位。

中文样式集中在 `frontend-next/src/styles/chinese.css`，由 `html[lang="zh-CN"]` 控制。产品分类的显示名称可以本地化，筛选值和接口字段继续使用稳定的英文标识。

## 参考与方法

- [AIbase 产品库](https://top.aibase.com/)：产品库、发现、最新产品等栏目用词。
- [通往 AGI](https://www.waytoagi.com/zh)：AI 产品和工具、知识库等社区用词。
- [小互 AI 工具社区](https://news.xiaohu.ai/c/aitools)：按具体用途描述产品。
- [Ant Design 文案规范](https://ant.design/docs/spec/copywriting-cn/)：从用户视角出发，准确、简洁，保持术语一致。
- [Impeccable clarify](https://impeccable.style/docs/clarify/)：检查整个操作流程中的按钮、空状态和错误恢复。作为公开写作参考使用。
- 本轮使用已安装的 `design-taste-frontend` 和 `vercel:react-best-practices` skills，分别检查视觉表达与 React 实现。

验收时覆盖中文和英文、明暗主题、窄屏、搜索跳转、分类筛选、收藏和已有演示。检查演示时优先使用已有内容，避免无意消耗生成次数。
